# 🛒 E-Commerce Sales Analysis — SQL

## 📌 Project Overview

This project analyzes e-commerce sales data using **SQL Server** to generate meaningful business insights related to customers, products, orders, revenue, and purchasing behavior.

The analysis uses multiple relational tables and SQL queries to identify sales trends, customer segments, top-performing products, payment preferences, and order patterns.

---

## 🗂️ Database Tables

- **Customers** — Customer details such as name, gender, age, city, state, and signup date
- **Products** — Product names, categories, and pricing information
- **Orders** — Order dates, order status, payment methods, and customer information
- **OrderDetails** — Product quantities and unit prices associated with each order

---

## 🔍 SQL Analysis Performed

The project includes queries for:

- Total customers, products, orders, and order details
- Total revenue
- Revenue by product
- Revenue by category
- Monthly revenue trends
- Customer total spending
- Top customers by spending
- Average order value
- Revenue by payment method
- Order status distribution
- Products ranked by units sold
- Customer order frequency
- Customer spending segments
- Revenue and orders by city
- One-time vs repeat customers
- Top revenue-generating products
